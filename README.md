# Сжато

Бесплатный Open Source сайт для сжатия и конвертации PDF и изображений, а также перепаковки ZIP/RAR в ZIP. Автор — Денис Шарапов. Оригинальный код — MIT; лицензии зависимостей в THIRD_PARTY_NOTICES.txt и public/licenses/.

[Открыть Сжато](https://project.it-kedr.ru/compressed) · [Каталог проектов](https://project.it-kedr.ru/) · [GitHub](https://github.com/DenKedr/szhato)

## Возможности

- Конвертер: PDF → JPEG/PNG/WebP, JPG/PNG/WebP → PDF и изображения между собой. [Открыть конвертер](https://project.it-kedr.ru/compressed?tool=convert). [Матрица и ограничения](docs/converter.md).

- Тёмный интерфейс в стиле iOS, компьютер и мобильный экран.
- PDF: минимальный размер по умолчанию на любом уровне (страницы становятся изображениями, теряются выделение/поиск текста, ссылки и формы). Можно вручную выбрать сохранение текста и JPEG-оптимизацию.
- Фото: три уровня качества/разрешения, JPG или WebP, сохранение прозрачности в автоматическом режиме; удаление EXIF при перекодировании.
- ZIP/RAR → ZIP: перепаковка без изменения содержимого вложений, DEFLATE1/6/9. Размер может увеличиться — статистика честно это показывает.
- Без числового лимита количества файлов; до500МиБ каждый и2ГиБ на очередь.
- Последовательная обработка, прогресс, отмена, повторное сжатие, отдельное скачивание и ZIP всех результатов с чтением по частям.
- Очистка исходников и результатов через15мин от добавления; повторное сжатие срок не продлевает. В приостановленной браузером вкладке проверка выполняется при возвращении и перед действиями. Скачанные копии не удаляются.

## Архивы и безопасность

Вложения обрабатываются в Web Worker как данные: не открываются, не исполняются, не добавляются в DOM, не записываются на реальный диск и не отправляются на сервер. Вложенные архивы рекурсивно не распаковываются. Это не антивирус: опасные вложения могут остаться в выходном ZIP.

Лимиты распаковки одного архива:10000записей,512МиБ суммарно,256МиБ на запись, коэффициент до200; preflight и контроль фактических байтов. Опасные пути, ссылки, специальные типы, шифрование, многотомность и самораспаковывающиеся EXE отклоняются. Worker завершается при отмене, истечении TTL и после120сек. Подробнее: [docs/archives.md](docs/archives.md).

500МиБ/2ГиБ — пределы входной очереди, а не гарантия достаточной памяти любого устройства. Изображения ограничены32Мп, PDF-растеризация150страницами. Подписанные, защищённые PDF и анимированные PNG/WebP отклоняются. HEIC/GIF/видео не поддерживаются.

## Разработка

Node.js22.12+ (ARM64 на Apple Silicon):

```sh
npm ci
npm run dev -- --port 5173
```

Dev: http://127.0.0.1:5173 .

```sh
npm test
npm run build
npm run preview -- --port 4173
```

Production preview: http://127.0.0.1:4173/compressed/ . Содержимое dist размещается в /compressed/; каталог из catalog/ — в корне домена. Не запускайте index.html через file://. На nginx .mjs должен иметь Content-Type application/javascript, .wasm — application/wasm. Строгий CSP допускает WebAssembly, но не требует unsafe-eval для JS.

## Проверка

npm test проверяет валидацию, пути/лимиты архивов, перепаковку PDF и результаты ZIP. При запущенном dev-сервере доступны browser-проверки tests/browser.mjs, tests/qa.mjs, tests/ttl.mjs, tests/archive-worker.mjs. Скрипты браузера используют Chrome на Mac; CHROME_PATH можно задать для другого окружения. Проверка выполняется локальными командами npm test и npm run build.

Проверяется фактический результат и сохранение данных, а не только отсутствие ошибок. Поддержка всех существующих вариантов архивов/кодировок не обещается; повреждённые или неподдерживаемые варианты возвращают ошибку. Safari/Firefox/iPhone отдельно не проверялись.
