# Конвертер

Открыть режим напрямую: https://project.it-kedr.ru/compressed?tool=convert . Обычный адрес сохраняет режим сжатия по умолчанию.

| Вход | Выход |
|---|---|
| PDF | JPEG (.jpg), PNG, WebP |
| JPG / JPEG | PNG, WebP, PDF, повторное сохранение JPEG |
| PNG | JPEG, WebP, PDF, повторное сохранение PNG |
| WebP | JPEG, PNG, PDF, повторное сохранение WebP |

PDF из одной страницы даёт отдельную картинку. Несколько страниц дают ZIP с именами страниц по порядку. Каждое изображение превращается в отдельный PDF, объединение нескольких фотографий в один документ в этот режим не входит. PDF → PDF выполняется в режиме сжатия, а не конвертации.

Конвертация возвращает выбранный формат даже когда результат больше исходника. Изображения не уменьшаются по разрешению; JPEG/WebP кодируются с выбранным качеством. PNG/WebP сохраняют альфа-канал, при JPEG прозрачность заменяется белым фоном. Метаданные EXIF удаляются при перекодировании, ориентация применяется к пикселям.

Для страниц PDF уровни качества задают216/144/96dpi. Реальное разрешение ограничено4096px по длинной стороне и12Мп на страницу, чтобы ограничить память устройства. До150страниц PDF, до512МиБ готового результата. Фотографии до32Мп и16384px по стороне. Общие ограничения500МиБ на входной файл и2ГиБ на очередь сохраняются; числового ограничения количества файлов нет.

Конвертация PDF — чтение и отрисовка страниц, без изменения исходника и выполнения встроенных действий. Подписанный PDF можно отрисовать, но криптографическая подпись не переносится в картинки. Зашифрованные PDF и анимированные изображения не поддерживаются. Переход в другой режим или формат не удаляет выбранные файлы молча и не продлевает их15минутный срок хранения. При неподходящей паре форматов появляется понятная ошибка.

Обработка локальная, без передачи содержимого файлов на сервер. Отмена и автоочистка действуют для конвертации так же, как для сжатия. Word/Excel/видео и другие не перечисленные здесь форматы не заявлены.
