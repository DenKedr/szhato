# Яндекс.Метрика

Денис попросил счётчик113884564 на всех старых, текущих и будущих страницах it-kedr.ru и его поддоменов. Сохранены параметры ssr, webvisor, clickmap, ecommerce=dataLayer, accurateTrackBounce, trackLinks, referrer и URL.

На текущем сервере используется общий nginx HTMLfilter с внешним загрузчиком. Это покрывает новые страницы независимо от системы сборки и сохраняется после смены релиза. Файлы deploy/analytics и deploy/nginx содержат загрузчик, шаблон и проверку публикации; настройки конкретных liveвиртуальныххостов хранятся на сервере. До выкладки следующего релиза нужно включать общий snippet и запускать /usr/local/sbin/it-kedr-check-metrika. Для нового поддомена подключение snippet обязательно. Политика находится также в AGENTS.md. На чужих доменах, localhost и сыром IP счётчик не запускается.

Скрипт вынесен во внешний файл согласно [рекомендации Яндекса для CSP](https://yandex.ru/support/metrica/ru/code/install-counter-csp). InlineJavaScript и JavaScript unsafe-eval не разрешаются ради Метрики. В CSP добавлены точные официальные адреса счётчика и интерфейсов просмотра. Ограничение встраивания сохраняется для остальных сайтов.

Webvisor получает обычный публичный интерфейс, но рабочая область файлов заранее скрыта классом ym-hide-content. У inputfile также ym-disable-keys, у временных ссылок скачивания ym-hide-content и ym-disable-tracklink. Это штатные [исключения записи контента](https://yandex.ru/support/metrica/ru/webvisor/settings). Пользовательские файлы обрабатываются локально; отдельные события с именами или содержимым файлов не отправляются. Аналитика посещений страницы передаётся Яндексу.

Один загрузчик и одна initкоманда на документ; повторное выполнение не создаёт повторный hit. Проверки при выпуске: HTML/noscript на всех публичных страницах и алиасах; реальная загрузка tag.js и успешные запросы watch/113884564; отсутствие CSPошибок; функции PDF/фото/ZIP и исключения рабочей области. При блокировщике рекламы счётчик может блокироваться на устройстве посетителя; это не повод обходить его выбор.
