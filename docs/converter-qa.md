# Независимая проверка конвертера

Статус: независимый UI-сценарий пройден в настоящем Google Chrome через Playwright. `node tests/converter-ui.mjs` завершился с кодом 0 и строкой `Converter UI checks passed.` Производственные файлы не изменялись. Новых дефектов в проверенных сценариях не обнаружено.

Команда после готовности приложения: `node tests/converter-ui.mjs` при локальном Vite на 127.0.0.1:5173. Можно задать `TEST_BASE_URL` и `CHROME_PATH`.

Сценарий проверяет deep-link `?tool=convert` и reload; drop PDF/фото/ZIP; сохранение несовместимой очереди при смене формата/инструмента; JPEG/PNG/WebP/PDF по расширению, MIME Blob и фактическим сигнатурам скачанных файлов; выдачу PNG, который больше исходного JPEG; отдельные PDF для двух фотографий и уникальные имена в общем ZIP; ZIP страниц многостраничного PDF; disabled переключатели при busy; TTL 15 минут без продления после конвертации и смены инструмента; регрессии сжатия фотографий, перепаковки ZIP, 25 файлов и ссылки GitHub.

## Подтверждённые результаты

- `?tool=convert` включает конвертер и сохраняет режим после перезагрузки. Переключение в сжатие убирает параметр, обратное переключение возвращает его.
- При drop PDF, фотографии и ZIP принимаются PDF/фото, для ZIP видна ошибка. Выбор целевого PDF с уже добавленным PDF не удаляет очередь: несовместимый файл указан, кнопка обработки заблокирована. Архив, добавленный в режиме сжатия, также сохраняется при переключении в конвертер с объяснением несовместимости.
- JPEG размером 13549 байт преобразован в PNG размером 214565 байт. Скачан именно `photo.png`, MIME `image/png`, PNG-сигнатура совпадает. Интерфейс честно показывает рост размера.
- Фотография в JPEG скачивается как `photo.jpg` / `image/jpeg`, в WebP — `photo.webp` / `image/webp`; сигнатуры файлов проверены.
- Два входных фото становятся двумя отдельными одностраничными PDF. Общий ZIP прочитан; `same.pdf` и `same (2).pdf` имеют уникальные имена и по одной странице.
- Двухстраничный PDF преобразован в `report-png.zip`, содержащий `page-001.png` и `page-002.png` с настоящими PNG-сигнатурами.
- Во время конвертации переключатели инструмента и целевого формата заблокированы. Завершение конвертации и переключение между инструментами не меняют исходный `data-expires-at`. В 15:00 событие focus удаляет очередь и результат.
- Сжатие фотографии и скачивание результата работают. После перепаковки ZIP содержимое `hello.txt` сохранено. 25 файлов принимаются; ссылка GitHub сохранена.
- В конвертере точная очередь 2 ГиБ принимается, следующий байт отклоняется; файл 500 МиБ принимается, 500 МиБ + 1 байт отклоняется. Это тест метаданных выбора, не обработки гигабайтовых изображений.

Время TTL симулируется Playwright Clock без изменения константы приложения и ожидания 15 реальных минут. Крупные лимиты 500 МиБ/2 ГиБ дополнительно проверяются в конвертере через метаданные файлов: точная граница принимается, превышение отклоняется; гигабайты памяти для этого не выделяются.

Тест не является полной проверкой всех PDF-кодеков и устройств: специализированные проверки движка, alpha/password/signed PDF/page limits выполняются отдельным `tests/conversion.mjs`. Визуальный layout этого этапа отдельно не проверялся. Все браузеры, созданные сценарием, закрыты.
