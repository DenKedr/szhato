# Перепаковка архивов

ZIP и RAR читаются локально в выделенном Web Worker и записываются в новый ZIP. Уровни DEFLATE: бережное1, оптимальное6, максимальное9. Содержимое вложенных файлов сохраняется побайтово. Изображения/PDF внутри архивов не пережимаются. Вложенные архивы рекурсивно не распаковываются. RAR на выходе не создаётся.

Ни один элемент архива не открывается в браузере, не вставляется в DOM, не импортируется как JavaScript и не запускается как программа. HTML, JS и исполняемые файлы остаются непрозрачными байтами. На сервер файлы не передаются; на реальный диск распаковка не выполняется. Скачанный архив может содержать опасные файлы: сервис не является антивирусом.

Лимиты выбора:500МиБ на файл,2ГиБ на очередь, без числового ограничения количества добавленных файлов. Это не обещание неограниченной памяти: скорость и доступные ресурсы зависят от браузера и устройства.

Поддерживаются обычные RAR4/RAR5; словарь до64МиБ. RAR7-only кодеки, расширенные служебные записи и некоторые редкие варианты формата отклоняются. Это намеренный отказ от неподдерживаемых структур, а не попытка частично выдать содержимое.

Отдельные ограничения безопасной распаковки: до10000записей внутри одного архива,512МиБ суммарно распакованных данных,256МиБ на запись, коэффициент распаковки до200. Проверяются заявленные размеры до распаковки и фактически выданные байты. Небезопасные пути, неоднозначные имена, символьные/жёсткие ссылки, специальные типы файлов, многотомные и зашифрованные архивы отклоняются. Самораспаковывающиеся EXE не поддерживаются.

Рабочий поток завершается при успехе, ошибке, отмене, истечении15мин хранения файла или превышении120сек на обработку. Оригинальный файл на устройстве не изменяется. ZIP возвращается даже когда перепаковка увеличила размер: в интерфейсе показывается реальная разница.
